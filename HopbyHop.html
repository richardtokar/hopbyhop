Your job

Address every frame the packet rides in.

A packet is travelling across the network. At each stop, you build the frame it leaves in by clicking addresses on the diagram. Get the four fields right and the packet moves to the next device.

  • IPSource and destination IP stay the same from start to finish. They always name the original sender and the final destination.
  • MACMAC addresses change on every link. Source MAC is the interface sending the frame. Destination MAC is the interface receiving it.
  • GATEWAYIf the destination is on a different network, the first frame goes to the default gateway (the router), not to the destination PC.

    Stuck? Rules of the road
    1. Find the device the packet is at right now. Its outgoing interface supplies the source MAC.
    2. Ask: is the final destination on this same network? If yes, the destination MAC is the destination PC. If no, it's the next router interface on this link.
    3. The source IP is always the PC that started the conversation.
    4. The destination IP is always the PC the packet is finally going to. Routers never put their own IP in these fields.
